# Agent Guide

This repository is a parody of a modern AI SaaS website. Keep that tone consistent.

## Core direction

- Build something that feels generic, polished, and slightly absurd.
- Lean into the usual AI product tropes: purple gradients, glossy cards, big claims, testimonials, pricing tiers, cookie banners, and a fake chatbot.
- Prefer surface-level completeness over real complexity.
- Make flows look functional even when they are mocked.

## Technical stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- lucide-react

## Deployment target

- Coolify

## Implementation notes

- Keep the UI cohesive and familiar.
- Fake interactions are fine where they support the parody.
- Avoid introducing unnecessary backend systems unless a task explicitly needs them.
