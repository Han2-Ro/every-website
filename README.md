# every-website ✨

An over-the-top, glossy AI SaaS parody built to look like the most generic product site on the internet. 🚀

## What this is 💅

This project is intentionally light on real functionality and heavy on polished vibes:

- landing page with purple gradients and glassmorphism ✨
- AI chatbot that mostly talks in buzzwords 🤖
- pricing page with subscription tiers 💳
- testimonials, cookie banner, and trust badges ✅
- fake login and onboarding flows that always "work" 🔐

## Stack 🧰

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- lucide-react

## Deployment ☁️

Target deployment is Coolify, using a standard container-based setup.

## Notes 📝

The goal is to feel familiar, polished, and vaguely impressive without requiring any real backend complexity.
